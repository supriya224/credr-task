# CredR Frontend Task

A responsive React/TypeScript implementation created as a frontend design and development task.

## Tech Stack

- React 18
- TypeScript
- Bootstrap
- Sass

## Getting Started

```bash
git clone https://github.com/supriya224/credr-task.git
cd credr-task
npm install
npm start
```

Open http://localhost:3000.

## Production Build

```bash
npm run build
```

## What This Project Demonstrates

- Responsive UI implementation
- Component-based React development
- TypeScript usage
- Sass-based styling
- Translating a product interface from requirements/design into code
